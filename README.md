Name: Fizza Batool

## Description

This is a simple university website for KIET (Karachi Institute of Economics & Technology). It is made using HTML, CSS and JavaScript.

The website has:
- Header and navigation menu
- About section with an image
- List of departments
- Table of academic programs
- Admission inquiry form
- Welcome message button (JavaScript)
- Contact section and footer

## Files

- index.html - main page
- style.css - design of the website
- script.js - JavaScript code
- kiet.jfif and std.jfif - images

## How to Run

1. Keep all the files in one folder.
2. Double-click index.html.
3. The website will open in your browser.
